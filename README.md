# My Project

💰 Personal Budget Tracker
A full-stack Python/Django web application designed to help users manage their finances by tracking income, expenses, and setting monthly budget limits with automated alerts.


✨ Features
Dashboard Overview: Visualize your total balance, monthly income, and current spending.

Expense & Income Tracking: Categorize your transactions (Food, Travel, Bills, etc.) and specify payment methods.

Budget Alerts: Set a monthly spending limit. The system automatically triggers a notification if your expenses exceed your predefined budget.

Account Management: Secure user authentication, profile updates, and account deletion.
Responsive UI: Clean, modern interface designed for both desktop and mobile use.


🛠️ Tech Stack

Backend: Django (Python 3.x)
Database: SQLite (default) or PostgreSQL
Frontend: HTML5, CSS3 (Custom Styles), JavaScript (ES6+)
Icons: FontAwesome
